# Showreel & Video Assets Directory

Place your showreel video file here:
- Filename: `showreel.mp4`
- Recommended format: H.264 / MP4 or WebM, 1080p or 4K DCI, 24fps
- Audio: 48kHz Stereo AAC / PCM

Optional project video clips can also be placed here:
- `projects/project-1.mp4`
- `projects/project-2.mp4`
- etc.

When `showreel.mp4` is present in this directory, the portfolio's dedicated showreel section and showreel modal will automatically load and play it. If the file is absent, the player displays an intentional, cinematic placeholder with instructions.
